# KRD Camera Pro

Kamera Android dengan fokus pada kualitas foto tinggi.

## Fitur
- Capture mode `MAXIMIZE_QUALITY`
- Autofocus & tap-to-focus
- Auto exposure / white balance dari CameraX
- Flash Auto / On / Off
- Kamera depan & belakang
- Zoom dasar
- Foto disimpan ke `Pictures/KRD Camera Pro`
- Struktur siap dikembangkan untuk HDR, Night Mode, Portrait/Bokeh, dan video 4K

## Build
Buka folder ini di Android Studio, tunggu Gradle sync, lalu pilih:
`Build > Generate App Bundle(s) / APK(s) > Generate APK(s)`

Catatan: kualitas akhir tetap bergantung pada sensor, lensa, ISP, dan dukungan hardware HP. Aplikasi tidak dapat mengubah sensor HP menjadi sensor iPhone.
